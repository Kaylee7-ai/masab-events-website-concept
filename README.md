# Masab Events — Website Concept

This is an independent website concept created as a proposal/demo for a potential client. **It is not the official Masab Events website and is not endorsed by the business.**

## Concept scope
- Responsive multi-page website: Home, Services, Weddings, Inspiration and Enquiries.
- Presentation of the business areas supplied for this concept: wedding planning and coordination, engagement/church/reception décor, bridal services, catering, beverages, cake, photography and videography, stationery, souvenirs, MC/DJ and other wedding needs. Contact and location details are based on promotional material supplied for this concept.
- Accra, Kumasi and nationwide service-area messaging.
- Mobile navigation and an enquiry-form interaction preview.
- Search-friendly page titles, descriptions and semantic HTML.

## Important before launch
1. Obtain the owner's written approval and confirm the exact business name, brand assets and service descriptions.
2. Replace all illustrative stock photography with images supplied or explicitly approved by the business. Verify usage permissions.
3. Confirm the business phone number, WhatsApp link, email, social links, service area wording, operating details and response expectations.
4. Connect the enquiry form to an owner-approved email/form service or WhatsApp destination. The current form is a preview only; it does not send or store submissions.
5. Add an appropriate privacy notice and required consent language before collecting personal information.
6. Confirm all service claims, testimonials, portfolio examples, pricing and policies with the owner. No testimonials or completed client projects have been invented in this demo.
7. Agree on scope, fees, timeline, hosting, domain ownership, payment milestones and support before accepting a build contract.

## Run locally
Open index.html in a browser, or use a simple local static server.

## Deploy a preview
This is a plain HTML, CSS and JavaScript site and can be hosted on GitHub Pages. In repository Settings, enable Pages using the main branch and root folder. Keep it clearly labelled as a concept until the business approves the site.

## Technology
- HTML5, CSS3 and vanilla JavaScript
- Google Fonts (Cormorant Garamond and Manrope)
- Illustrative remote Unsplash photography (replace before official launch)
